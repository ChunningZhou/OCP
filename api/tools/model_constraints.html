model_constraints#

Model-level SAT/MILP constraints for cryptanalysis.

This module provides: 1. Model-level constraint encodings

  • Predefined value/cardinality constraints (EXACTLY, AT_LEAST, SUM_AT_MOST, …)

  • SAT sequential-counter cardinality encoding

  • Matsui’s branch-and-bound constraints for MILP/SAT trail search

  1. Attack boundary/input constraints shared by the differential and linear cryptanalysis - Nonzero input constraint builder - Fixed input/output difference or mask constraints for hull/probability goals

tools.model_constraints.gen_predefined_constraints(model_type, cons_type, cons_vars, cons_value, bitwise=True, encoding=None)[source]#

Generate commonly used, predefined model constraints based on type and parameters.

Parameters:

  • model_type (str) – The model backend, "milp" or "sat".

  • cons_type (str) – The constraint type, must be one of the predefined types: - “EXACTLY”: All selected variables == a target value. - “AT_LEAST”: All selected variables >= target value. - “AT_MOST”: All selected variables <= target value. - “SUM_EXACTLY”: Sum of selected variables == target value. - “SUM_AT_LEAST”: Sum of selected variables >= target value. - “SUM_AT_MOST”: Sum of selected variables <= target value.

  • cons_vars (list) – Variable names or Variables objects with ID and bitsize attributes.

  • cons_value (int) – Target value.

  • bitwise (bool) – If True, expand variables by bit.

  • encoding – SAT cardinality encoding passed to the backend (ignored for MILP; None selects the default).

Returns:

List of generated model constraint strings.

Return type:

list[str]

tools.model_constraints.gen_no_good_cut(var_ids, bits, model_type='milp')[source]#

No-good cut forbidding one 0/1 assignment bits over var_ids, forcing any later solution to differ in at least one of these variables (e.g. to enumerate distinct solutions).

MILP: sum_{b=0} v + sum_{b=1} (1 - v) >= 1 SAT : one blocking clause = OR of the negated literals of the assignment.

Returns a list with the single constraint string (empty list if var_ids is empty).

tools.model_constraints.state_bits(cons_vars, fixed_value, value_name='value')[source]#

[(var_id, bit)] for cons_vars pinned to fixed_value, MSB first.

The traversal anything pinning a state needs: the word count and the word width come from the variables themselves, so a caller cannot disagree with the primitive about how a state splits. fixed_value is the whole state as "0x..." / "0b...", MSB first, and must match the target’s width – a value wider than its target is rejected, never truncated.

Separate from _fix_vars_to_bits because a caller may want the assignment rather than the constraints: reference/convert.py had its own copy of this loop for exactly that reason.

tools.model_constraints.state_var_ids(cons_vars)[source]#

The model variable IDs of a state, MSB first – the order a state’s value is read in.

Split out so reading a value off a solution uses the same order as pinning one into a model; the two directions disagreeing would make a claim written here unreadable there.

tools.model_constraints.gen_fixed_input_output_constraints(in_out, fixed_value, cipher, model_type, value_name='value')[source]#

Generate constraints that fix input/output differences or masks.

tools.model_constraints.gen_fixed_activity_constraints(cons_vars, active_positions, model_type='milp', bitwise=False)[source]#

Fix an activity pattern over cons_vars: positions in active_positions are 1, the rest 0.

bitwise=False counts one position per variable (word-level, for a truncated model); bitwise=True counts one per bit. Positions index the expanded list, so with bitwise the i-th position is the i-th BIT across all the variables.

tools.model_constraints.gen_fixed_state_constraints(cipher, function, rnd, layer, fixed_value, model_type, nwords=None, value_name='value')[source]#

Fix the state of function at round rnd, layer layer to fixed_value.

Addresses cipher.functions[function].vars[rnd][layer], so the word count and the word width are read from the cipher. fixed_value is the whole state as a "0x..."/"0b..." string, MSB first, and must match the target’s width. Pick only the first nwords words.
