model_configuration#

Model-building configuration for cipher analysis.

tools.model_configuration.fill_functions_rounds_layers_positions(cipher, functions=None, rounds=None, layers=None, positions=None)[source]#

Fill in functions, rounds, layers, and positions to full coverage when the corresponding argument is None; otherwise, keep user-supplied values.

Parameters:

  • cipher (object) – The cipher object.

  • functions (list[str]) – List of functions. If None, use all functions of the cipher. Example: [“PERMUTATION”, “KEY_SCHEDULE”, “SUBKEYS”].

  • rounds (dict) – Dictionary specifying rounds. If None, use all. Example: {“PERMUTATION”: [1, 2, 3]}.

  • layers (dict) – Dictionary specifying layers. If None, use all. Example: {“PERMUTATION”: {1: [0, 1], 2: [0, 1], 3: [0, 1]}}.

  • positions (dict) – Dictionary specifying positions. If None, use all. Example: {“PERMUTATION”: {1: {0: [0, 1], 1: [0, 1]}, 2: {0: [0, 1], 1: [0, 1]}, 3: {0: [0, 1], 1: [0, 1]}}}.

Returns:

(functions, rounds, layers, positions)

Return type:

tuple

tools.model_configuration.configure_model_version(cipher, goal, config_model)[source]#

Assign each in-scope constraint the model version required by goal.

Applies the (version, operator_name) rules from GOAL_MODEL_VERSION_RULES, then any explicit overrides in config_model["model_version"]. The override is a {operator_name: version} dict, so different operators can take different versions; a None key targets every operator and is applied first, so named-operator entries win on overlap (e.g. {None: "XORDIFF", "Sbox": "XORDIFF_PR"}).

tools.model_configuration.operator_in_scope(operator_class, operator_name)[source]#

Whether operator_class is covered by the operator_name scope of a version rule.

None covers every operator. "Sbox" covers every S-box.

tools.model_configuration.scoped_constraints(cipher, functions, rounds, layers)[source]#

Every operator of cipher inside the given scope, inputs and outputs included.

tools.model_configuration.set_model_versions(cipher, version, functions, rounds, layers, positions, operator_name=None)[source]#

Assign a model version to matching constraints in the selected cipher scope.

tools.model_configuration.model_scope(cipher, config_model)[source]#

[(round, cons)] for exactly the operators a model will be generated for.

round is None for the boundary constraints. Shared with the check below so the two cannot disagree about scope: set_model_versions assigns more broadly, and checking that wider set would reject requests that generate fine. A list, so both passes see it.

tools.model_configuration.check_assigned_model_versions(cipher, config_model)[source]#

Raise once, naming every operator left with a version it does not declare.

Reads the versions actually assigned, not the goal’s rules, so a model_version override is accepted when it works. Exemptions match Operator.check_supported_model_version: nothing new is refused, only refused before any model is built.
