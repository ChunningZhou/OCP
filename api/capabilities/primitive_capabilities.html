primitive_capabilities#

The cipher catalogue: which primitives exist, how a factory is called, which versions it takes.

capabilities.primitive_capabilities.version_tables(module)[source]#

{class or factory name: {version: full round count}} for the multi-version primitives.

The only place the documented versions are written down; building gives one round count, not the catalogue. Two idioms normalised to one shape: full_rounds in a class __init__, and a module-level <FACTORY>_VERSIONS carrying nbr_rounds (primitives/knot.py). A single-version primitive has no table.

Enforced since 2026-10-10: each of the 13 raises [ERROR] Unknown version <v> for <Class>. Expected one of <keys>. before building anything, guarded by test_every_version_table_is_enforced. Until then none of them checked, and SPECK_PERMUTATION(version=12345) returned SPECK12345_PERM with a 6172-bit word. The absence of a table is still not evidence that anything goes: 21 factories have none and nothing constrains their version – see TODO.md.

capabilities.primitive_capabilities.primitive_factories(include_in_development=False)[source]#

{(module, factory): {...}} for every module-level cipher factory. Builds nothing.

Per entry: parameters as {name: {required, default}}, kept apart because a required argument and one defaulting to None are both absent from a signature read as {name: default} – today no factory has a required argument, so every one of the 32 ready factories can be called with none; version_shape and version_default; builds (statically inferred, see _instantiated_class); version_rounds (the documented table, which the factory now enforces – see version_tables) and version_keys_are_arguments; in_development.

capabilities.primitive_capabilities.describe_primitive(module, factory, **kwargs)[source]#

Build one cipher and report what only an instance can say.

Adds name, kind, nbr_rounds, test_vectors and the built cipher itself to the static entry, or error when the factory raises. Separate from primitive_factories because building all 34 takes about 3 seconds.

cipher is handed back so a caller that needs the instance does not build a second one – TRIVIUM alone costs 2.7 s, and two builds are two chances to differ. It is the one non-serialisable field in the entry; drop it before writing the entry out.
