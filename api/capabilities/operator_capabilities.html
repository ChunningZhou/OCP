operator_capabilities#

What each operator declares it can model and emit, cross-checked against its source.

capabilities.operator_capabilities.operator_classes(declaring_only=False, include_in_development=False)[source]#

{class name: class} for every concrete Operator subclass under operators/.

declaring_only=True keeps the classes with a non-empty declaration, and {"milp": ()} counts – empty version tuples are a statement. Keyed by __name__; two classes sharing it raise rather than overwrite.

capabilities.operator_capabilities.describe_operators(include_in_development=False)[source]#

{operator: {module, model_versions, implementations}} from the declarations themselves.

Only classes declaring SUPPORTED_MODEL_VERSIONS in their own __dict__; one that inherits it (every named S-box inheriting Sbox) is represented by the declaring base. model_versions is the class’s own declaration, implementations the effective value after inheritance, and implementations_declared_here says whether it overrides.

capabilities.operator_capabilities.delegates(operator_class)[source]#

Whether the class declares it passes its model_version down to inner operators.

capabilities.operator_capabilities.models_nothing(operator_class)[source]#

Whether operator_class declares every model_type with no supported versions.

capabilities.operator_capabilities.extract_from_source()[source]#

{operator: set(model_version_suffixes)} statically parsed out of generate_model.

capabilities.operator_capabilities.source_models_nothing()[source]#

The operators whose generate_model cannot return anything, parsed statically.

A heuristic, not an analysis: the converse is weaker, so the proof is a test that calls them.

capabilities.operator_capabilities.extract_implementations_from_source()[source]#

{operator: set(languages)} that generate_implementation branches on, statically.

capabilities.operator_capabilities.consistency_report(include_in_development=False)[source]#

Diff the declarations against the source; {operator: {...}}, empty when they agree.

Per operator, any of: missing (the code handles it but the declaration omits it – real drift), extra (declared but not seen statically, usually benign), declares_no_model / source_has_no_model, implementations_missing / implementations_extra. An empty report does not prove the declarations; verification_coverage() says what it reaches.

capabilities.operator_capabilities.verification_coverage()[source]#

What consistency_report() actually proves, and what it leaves unverified.
