solving#

This module provides tools for solving MILP/SAT models. Supports multiple solvers and configurations.

  • MILP solvers: Gurobi, SCIP

  • SAT solvers: PySAT, OR-Tools CPSAT, external DIMACS binaries (e.g., PRS, CaDiCaL, CryptoMiniSat, Kissat)

solving.solving.normalize_sat_solver_name(solver='DEFAULT', backend=None)[source]#

Normalize a SAT solver name to a supported value, raising on unknown.

backend selects the solving engine explicitly and takes precedence over name-based matching. This disambiguates solver names shared by more than one backend (e.g. PySAT’s “CryptoMinisat” vs the external “CryptoMiniSat” binary, identical once lowercased): set backend="pysat" or backend="external" to pick. With backend=None the name is matched against the PySAT names first (preserving historical behaviour), then the external registry.

solving.solving.solve_milp(filename, config_solver=None)[source]#

Solve a MILP model.

Parameters:

  • filename (str) – Path to the MILP model file.

  • config_solver (dict) –

    • solver: solver name (e.g. “GUROBI”, “SCIP”).

    • solution_number: The number of solutions to find (default: 1).

Returns:

A list of solutions. Each solution is represented as a dictionary mapping variable names to their values.

solving.solving.solve_sat(filename, variable_map, config_solver=None)[source]#

Solve a SAT problem (DIMACS CNF filename).

Parameters:

  • filename (str) – Path to the CNF file.

  • variable_map (dict) – Mapping of variable names to their DIMACS integer ids.

  • config_solver (dict) –

    • solver: solver name (e.g. “DEFAULT”, “ORTools”, “Cadical103”,

      or an external binary: “PRS”, “CaDiCaL”, “CryptoMiniSat”, “Kissat”).

    • backend (optional): “pysat” or “external”; disambiguates solver names

      shared by both backends (e.g. PySAT “CryptoMinisat” vs the external “CryptoMiniSat” binary). See normalize_sat_solver_name().

    • solution_number: The number of solutions to find (default: 1).

Returns:

Up to solution_number solutions, each a dict mapping variable names to 0/1;

an empty list if unsatisfiable. An unloadable backend raises an exception.

Return type:

list

solving.solving.solve_sat_pysat(filename, variable_map, config_solver)[source]#

Solve a SAT model (DIMACS CNF filename) with PySAT.

Shared arguments as in solve_sat(). Returns up to solution_number {variable_name: 0/1} solutions; raise if PySAT is unavailable.

solving.solving.solve_sat_cpsat(filename, variable_map, config_solver)[source]#

Solve a SAT model (DIMACS CNF filename) with Google OR-Tools CP-SAT.

Shared arguments as in solve_sat(). Returns up to solution_number {variable_name: 0/1} solutions; raise if OR-Tools CP-SAT is unavailable. Known difference: multi-solution enumeration is callback-based and does not project blocking clauses onto trail_var_names (unlike the PySAT/external backends).

solving.solving.solve_sat_external(filename, variable_map, config_solver)[source]#

Solve a SAT model (DIMACS CNF filename) with an external binary registered in EXTERNAL_SAT_SOLVERS.

Shared arguments as in solve_sat(). Extra config_solver keys:

  • solver_bin: binary path/name overriding the registry default (optional).

  • solver-specific keys read by the registry builder (e.g. threads for PRS).

Returns up to solution_number {variable_name: 0/1} solutions, or None if the solver binary is unavailable; the list is empty (or cut short) on UNSAT or timeout.
