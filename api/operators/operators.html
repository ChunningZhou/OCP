operators#

Operator (constraint) nodes of OCP’s graph model.

An Operator relates a group of input variables to a group of output variables. Every concrete operator provides two code generators:

  • Operator.generate_implementation() – executable code for the operator in a target language (python/c/verilog), selected by the operator’s implementation_type.

  • Operator.generate_model() – SAT/MILP constraint strings for a cryptanalysis model (differential / linear / integral), selected by the operator’s model_version.

class operators.operators.Operator(input_vars, output_vars, model_version=None, ID=None)[source]#

Bases: ABC

Abstract base for every operator (constraint) node in the cipher graph.

An Operator relates its input_vars to its output_vars and knows how to emit both an executable implementation and a cryptanalysis model of that relation.

Variables:

  • input_vars (list) – The operator’s input variables (each entry a Variable, or a list of Variables for word/vector operands).

  • output_vars (list) – The operator’s output variables (each entry a Variable, or a list of Variables for word/vector operands).

  • model_version (str) – The model to emit, as '<ClassName>_<SUFFIX>' (e.g. 'XOR_XORDIFF'); set before calling generate_model().

  • ID (str) – Identifier for the operator instance.

  • is_ghost (bool) – Whether this operator was marked ghost during dead-end removal.

check_supported_model_version(model_type)[source]#

Reject a model_version not declared for model_type in SUPPORTED_MODEL_VERSIONS.

SUPPORTED_MODEL_VERSIONS maps each model_type (‘sat’/’milp’) to the version suffixes it accepts; each is prefixed with the class name to form the '<ClassName>_<SUFFIX>' value that generate_model compares model_version against.

get_var_ID(in_out, index, unroll=False)[source]#

Return the ID of the input/output (‘in’/’out’) variable at index.

When unroll is False the round index is stripped from the ID (so the same code can be reused across rounds); when True the fully-qualified ID is returned.

get_header_ID()[source]#

generate_implementation_header(implementation_type='python')[source]#

get_var_model(in_out, index, bitwise=True, dim=1)[source]#

Return the model-variable name(s) for the input/output variable at index.

With bitwise True and a multi-bit variable, one name per bit is returned; dim > 1 additionally expands a trailing dimension (e.g. parallel words).

abstract generate_implementation(implementation_type='python')[source]#

Return executable code (a list of source lines) computing this operator.

implementation_type selects the target language (one of SUPPORTED_IMPLEMENTATIONS, typically ‘python’/’c’/’verilog’).

abstract generate_model(model_type='sat')[source]#

Return the cryptanalysis-model constraints (a list of strings) for this operator.

model_type is ‘sat’ or ‘milp’; the cryptanalysis technique (differential / linear / integral) is selected by self.model_version (see SUPPORTED_MODEL_VERSIONS). Implementations may also set self.weight as a side effect.

class operators.operators.CastingOperator(input_vars, output_vars, ID=None)[source]#

Bases: Operator

Abstract base for casting operators (casting from one type to another).

Casting operators must preserve the total bit width. Concrete subclasses are expected to define implementation/model generation for their specific layout.
