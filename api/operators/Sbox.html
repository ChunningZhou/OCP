Sbox#

S-box operators: the generic Sbox plus the named S-boxes of the supported ciphers (AES, PRESENT, GIFT, SKINNY, ASCON, RECTANGLE, TWINE, KNOT, PRINCE, LBlock, …).

Each S-box computes its DDT/LAT and differential/linear branch numbers, generates lookup-table implementations (python/C/Verilog, including the bit-sliced form), and builds SAT/MILP models from cached constraint templates – regenerating a template via espresso / convex-hull only when it is not already cached under files/sbox_modeling/.

Return the differential branch number: the minimum non-zero combined Hamming weight of an input difference and its output difference through the S-box.

Return the linear branch number: the minimum non-zero combined Hamming weight of an input mask and an output mask with non-zero correlation (a non-zero LAT entry).

is_bijective()[source]#

Return True if the S-box is a bijection (its table is a permutation of 0..2^n-1).

star_ddt_to_truthtable()[source]#

Truth table of the star-DDT: 1 for every possible (input diff, output diff), without probabilities.

pddt_to_truthtable(p)[source]#

Truth table of the p-DDT: 1 for every (input diff, output diff) whose DDT entry equals p.

ddt_to_truthtable_milp()[source]#

Truth table encoding the DDT with probability weights for the MILP model (weight bits are the real-valued -log2 probability).

ddt_to_truthtable_sat()[source]#

Truth table encoding the DDT with probability weights for the SAT model (weight bits are a unary integer part plus one-hot fractional part).

star_lat_to_truthtable()[source]#

Truth table of the star-LAT: 1 for every possible (input mask, output mask) with non-zero correlation, without correlation magnitudes.

plat_to_truthtable(p)[source]#

Truth table of the p-LAT: 1 for every (input mask, output mask) whose LAT entry is +/- p.

lat_to_truthtable_milp()[source]#

Truth table encoding the LAT with correlation weights for the MILP model (weight bits are the real-valued -log2 correlation).

lat_to_truthtable_sat()[source]#

Truth table encoding the LAT with correlation weights for the SAT model (weight bits are a unary integer part plus one-hot fractional part).

gen_spectrum(table)[source]#

Return the sorted distinct non-trivial magnitudes in table (a DDT/LAT), excluding 0 and the full value 2^input_bitsize.

gen_weights(table)[source]#

Return the -log2 probability/correlation weight of each spectrum value of table.

gen_integer_float_weight(table)[source]#

Split the weights of table into their sorted distinct integer and fractional parts.

gen_weight_pattern_sat(integers_weight, floats_weight, w)[source]#

Encode weight w as the SAT weight-bit pattern: a unary integer part padded to the max integer weight, followed by a one-hot selector over the fractional parts.

Return executable code (a list of source lines) computing this operator.

implementation_type selects the target language (one of SUPPORTED_IMPLEMENTATIONS, typically ‘python’/’c’/’verilog’).

get_header_ID()[source]#

Return [class name, model_version], identifying the operator’s model header.

generate_implementation_header(implementation_type='python')[source]#

Return code emitted once before the operator’s implementation (default: none).

generate_model(model_type='sat', tool_type='minimize_logic', mode=0, filename_load=True)[source]#

Return the cryptanalysis-model constraints (a list of strings) for this operator.

model_type is ‘sat’ or ‘milp’; the cryptanalysis technique (differential / linear / integral) is selected by self.model_version (see SUPPORTED_MODEL_VERSIONS). Implementations may also set self.weight as a side effect.
