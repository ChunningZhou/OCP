run#

Replaying recorded claims through OCP, cheapest first, resumably.

recheck.run.width_of(spec)[source]#

The primitive’s state width in bits.

Usually the version kwarg says it, but a primitive fixed to one block size takes no such kwarg – PRESENT is 64 bits and says so nowhere in the claim. Falling back to 0 there would order full-round PRESENT ahead of every two-round SPECK32, so the width is measured off a one-round instance instead and cached per target.

recheck.run.label_of(spec)[source]#

A short name for the target, for the dry-run listing.

recheck.run.canonical(path)[source]#

One identity per claim file, whatever spelling reached us.

The resume key is the path, so reference/data/x.json and its absolute form have to be the same job – otherwise narrowing a run to one file by typing a relative path re-runs everything the default (absolute) pattern already recorded. realpath matches the Path.resolve() the default pattern is built from, symlinks included.

recheck.run.jobs(patterns, max_version, max_rounds, analyses)[source]#

One job per (claim file, round count): the unit a single search covers.

Each job is (cost, path, kind, rounds, label).

recheck.run.done_keys(log, model_type)[source]#

Jobs already recorded for this backend.

The key is (file, rounds, model_type), so switching from SAT to MILP (or vice versa) replays everything instead of silently reusing the other backend’s results.

recheck.run.run_one(path, kind, rounds, model_type, config_solver, cache)[source]#

One job, as (checks, whether a search actually ran, the optimum found).

The optimum is returned separately so the log can carry it as a number. It also appears inside each check’s detail, but that is prose for a human reading the run; make_table fills the table’s OCP column from the field, rather than parsing a sentence that may be reworded. It is None for a trail claim, which pins a trail instead of searching for an optimum.

Bound searches are shared through cache: a target claimed by three papers is searched once and compared three times. Roughly half the recorded claims are such repeats.
